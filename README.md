
# Skin Cancer Classification Using CNN

## Project Overview
This project uses a Convolutional Neural Network (CNN) to classify skin images into two categories:

- Benign
- Malignant

## Technologies Used
- Python
- TensorFlow
- CNN
- Streamlit
- NumPy
- Pillow

## Dataset
The dataset contains benign and malignant skin images.

## Model
A lightweight CNN model is trained to classify skin images.

## Features
- Upload skin images
- Image preprocessing
- CNN-based prediction
- Display prediction results

## How to Run

Install the required libraries:

pip install -r requirements.txt

Run the application:

streamlit run app.py

## Disclaimer
This project is for educational purposes only. It is not a medical diagnostic tool. Always consult a qualified dermatologist.
